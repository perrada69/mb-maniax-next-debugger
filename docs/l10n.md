# Překlady (l10n)

Jazyky: `en` (výchozí, záloha), `cs`, `sk`, `es`, `de`, `fr`, `it`, `pl`, `pt-br`, `ru`, `uk`, `ja`, `zh-cn`.

Výběr jazyka (`extension/src/i18n.ts`, `setLanguage`): nastavení `mbxNext.language` (`auto` nebo kód),
při `auto` jazyk VS Code, pokud není angličtina, jinak jazyk systému, jinak angličtina. Samostatný
adaptér (`dist/adapter.js`) bere `MBX_NEXT_LANG`, jinak jazyk systému.

## Slovníky

`extension/l10n/<oblast>.json` – jeden soubor na oblast, všechny jazyky v něm:

```json
{
    "en": { "session.serverNotFound": "Debug server not found ({0}). Set mbxNext.serverPath." },
    "cs": { "session.serverNotFound": "Ladicí server nenalezen ({0}). Nastavte mbxNext.serverPath." },
    "sk": { … }, …
}
```

- Klíč = `<oblast>.<názevVCamelCase>`; oblast = jméno souboru (`session`, `screen`, `next`,
  `sprites`, `patterns`, `palettes`, `layers`, `layer2`, `tilemap`, `copper`, `nextreg`).
  Každý soubor smí obsahovat jen klíče své oblasti.
- Každý klíč ve VŠECH 13 jazycích. Angličtina je zdroj pravdy pro význam; česky je původní text.
- Parametry `{0}`, `{1}` …; čísla, hex hodnoty (`$4B`), jména registrů (`NR $43`), zkratky hardwaru
  (`Layer 2`, `ULA`, `Copper`, `NEXTREG`, `MMU`, `DMA`, `ULANext`, `LoRes`, `RGB333`) se nepřekládají.
- Krátké popisky v UI krátce (záložky, sloupce tabulek) – ověř, že se nerozbije rozložení
  (němčina a ruština bývají delší).
- Terminologie VS Code v daném jazyce (Breakpoint, Watch, Debug Console … tak, jak je VS Code překládá).

## Použití

- TypeScript (rozšíření, adaptér): `import { t } from './i18n'; t('session.serverNotFound', path)`.
- Webview panelu Next: `api.t('sprites.visibleOnly')`; při registraci `NextView.t(...)` (např. `title`).
  `api.lang` / `NextView.lang` = kód jazyka (formát čísel, `toLocaleString`).
- Webview obrazovky (`media/screen.js`): `window.L10N.texts` / vlastní malé `t` se stejným chováním.
- Rozšíření vkládá slovník do webview přes `dictionaryScript(nonce, ...předpony)` z i18n.ts
  (`<script nonce>` před ostatními skripty), `<html lang>` = `language()`.
- `package.json`: texty jako `%klíč%`, překlady v `package.nls.json` (en) a `package.nls.<jazyk>.json`
  (jazyk VS Code; `sk` VS Code oficiálně nemá, ale soubor nevadí).

Komentáře ve zdrojácích zůstávají česky.
